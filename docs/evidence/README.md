# Evidence Layer: `docs/evidence/<feature>/`

Physical, reproducible proof — never trust "tests passed" without artifacts.

```text
docs/evidence/<feature>/
├── audit-trail.json   # kb tool calls behind the spec citations (Phase 1)
├── test-run.txt       # raw stdout + exit code of the final test run (Phase 3)
├── qa-defects.json    # structured QC defect report & circuit breaker tracker (Phase 3)
└── visuals/           # Playwright screenshots / sample API payloads (UI only)
```

## audit-trail.json

Recorded by the agent at Gate 1, one entry per grounding query:

```json
{
  "session_id": "ses_...",
  "records": [
    {
      "query": "keyset pagination cursor page token performance",
      "book": "API Design Patterns",
      "citation": "API Design Patterns — 21 > Page tokens — p.326",
      "chunk_id": "<from tool result>",
      "score": 0.87
    }
  ]
}
```

Rule: every citation in `docs/specs/<feature>.md` MUST have a matching record
here (same chunk_id). `gate check` verifies the session made the calls;
spot-verify chunk_ids with `kb get-passage` on suspicion.

## test-run.txt

Captured by `gate evidence <feature> -- <test-command>`: full stdout/stderr
plus `EXIT CODE:` trailer. A claim of "all green" without this file is void.
Must show the FULL suite (no `-k` cherry-picking, no skips hidden).

## qa-defects.json

Machine-readable defect report generated by Phase 3 (QC) during verification.
Tracks adversarial findings and manages the Circuit Breaker loop (max 3 cycles).

```json
{
  "feature": "invoice-export",
  "phase": "qc",
  "cycle": 1,
  "max_cycles": 3,
  "status": "FAILED",
  "defects": [
    {
      "id": "DEF-001",
      "severity": "CRITICAL",
      "layer": "backend",
      "ac_id": "AC-2",
      "summary": "Idempotency key collision creates duplicate invoice records",
      "file": "src/services/invoice.ts",
      "line": 45,
      "reproduce": {
        "command": "npm run test:concurrency",
        "payload": {"idempotency_key": "test_dup_123", "amount": 500}
      },
      "expected": "HTTP 409 Conflict on duplicate idempotency key",
      "actual": "HTTP 200 Created with duplicate database row",
      "invariant_ref": "API Design Patterns (Request Deduplication) — p.415",
      "resolved": false
    }
  ]
}
```

Rules:
- Agent DEV reads `defects` where `resolved == false`, implements the fix, and runs tests.
- Agent QC re-verifies and sets `resolved: true`.
- If `cycle > 3` with unresolved `CRITICAL` or `HIGH` defects, status becomes `BLOCKED` (Circuit Breaker halts autonomous loop).
